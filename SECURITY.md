# Security Policy

Never send secrets, raw feedback, real names, IP addresses or student/teacher data in a GitHub Issue or pull request.

## Reporting a security issue

If you find an RLS bypass, exposed raw content, identity leak, API key leak or admin authorization bug, report it privately to a maintainer instead of publishing it. Include the impact, minimal reproduction steps and the affected release/commit.

Maintainers must rotate compromised secrets, preserve an audit trail and communicate the impact before publishing technical details.
