# Governance

- Organization Owner: the project owner and highest authority for the TLTP repository.
- Maintainers: handle operations and reviews; grant Admin only when truly necessary.
- Coders/contributors: contribute through forks and pull requests; never push directly to `main`.

Branch protection requires passing CI, at least one review, no force-push and squash merges. Changes to permissions, policies, the database schema or privacy require maintainer review.
