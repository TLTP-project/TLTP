# Code of Conduct

TLTP is a project for the school environment. Everyone must communicate respectfully, avoid personal attacks, never publish identifying student/teacher data and never use an issue or PR to retaliate against a feedback post.

Harassment, doxxing, discrimination, spam or deliberate privilege escalation may result in content removal, contribution restrictions or an account ban at the maintainers' discretion.

If a problem occurs, contact a maintainer through the private channel described in Security/Governance; do not publish private information in a public issue.
